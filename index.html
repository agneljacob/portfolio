From Web Apps to Infrastructure

Why cloud & DevOps

I started where most developers do — building web applications and learning to make features work. But the questions that kept pulling at me were the ones after the code was written: how does this get deployed, how does it stay online, how do you ship a change without breaking everything? That's what pointed me toward cloud and DevOps. I graduated in Computer Applications from De Paul Institute of Science and Technology with a foundation in web and database work, and I'm now spending my time learning Linux, Docker, AWS, and CI/CD. I'm early in this — I'm not going to pretend otherwise — but I finish what I start and I learn fastest by building real things.

01

I'd rather ship a small, working project than collect certificates. Understanding comes from doing.

02

Understand before automating

Automation is only useful once you know the manual steps cold. I focus on the fundamentals first.

Half-built projects teach half-lessons. I see things through to something that actually runs.
